# 주차 정보 UART 패킷 프로토콜 명세서

## 1. 개요 (Overview)

본 문서는 **ParkingDetect (주차 감지 모듈)** 에서 **InfoMark (안내 디스플레이 / 메인 제어기)** 로 전송하는 주차 슬롯 점유 상태 데이터의 **UART 통신 프로토콜 및 패킷 포맷**을 정의합니다.

## 2. 통신 기본 규격 (Physical Layer)

| 항목 | 설정값 |
|---|---|
| **통신 인터페이스** | UART / USART (USART1) |
| **Baud Rate** | 115200 bps |
| **Data Bits** | 8 Bits |
| **Parity** | None |
| **Stop Bits** | 1 Bit |
| **Flow Control** | None |
| **전송 포맷** | ASCII 텍스트 (줄바꿈 `\n` 종단) |

## 3. 패킷 규격 상세 (Packet Specifications)

### 3.1. 전체 주차 슬롯 상태 패킷 (`$PARK`)

주차 슬롯(10개 채널) 중 어느 하나라도 점유/비점유 상태가 변경되었을 때, 전체 10개 슬롯의 최신 상태를 동기화하기 위해 송신되는 기본 패킷입니다.

#### 📌 포맷 구조
```text
$PARK,<슬롯1>:<상태>,<슬롯2>:<상태>,...,<슬롯10>:<상태>\n
```

#### 📌 필드 상세
| 필드명 | 타입 | 설명 | 예시 |
|---|:---:|---|---|
| **Header** | String | 패킷 시작 식별자 | `$PARK` |
| **Delimiter** | Char | 슬롯 간 구분자 | `,` (콤마) |
| **Slot Name** | String | 주차 구역 식별자 | `A-01` ~ `A-06`, `B-01` ~ `B-02`, `C-01` ~ `C-02` |
| **Separator** | Char | 슬롯명과 상태값 구분자 | `:` (콜론) |
| **Status Value** | Integer | 주차 점유 여부<br>• `0`: 빈자리 (**EMPTY**)<br>• `1`: 주차중 (**OCCUPIED**) | `0` 또는 `1` |
| **Terminator** | Char | 패킷 종료 문자 | `\n` (`0x0A`, LF) |

#### 📌 실제 전송 예시
```text
$PARK,A-01:1,A-02:0,A-03:0,A-04:1,A-05:0,A-06:0,B-01:0,B-02:1,C-01:0,C-02:0\n
```

> **해석**:
> - 점유 중 (`1`): **A-01, A-04, B-02**
> - 빈자리 (`0`): **A-02, A-03, A-05, A-06, B-01, C-01, C-02**

---

### 3.2. 단일 슬롯 상태 변경 이벤트 패킷 (`$EVENT`)

특정 1개 슬롯의 상태 변화 이벤트만을 즉시 전송할 때 사용하는 패킷입니다.

#### 📌 포맷 구조
```text
$EVENT,<슬롯명>:<상태문자열>\n
```

#### 📌 필드 상세
| 필드명 | 타입 | 설명 | 예시 |
|---|:---:|---|---|
| **Header** | String | 단일 이벤트 식별자 | `$EVENT` |
| **Slot Name** | String | 대상 슬롯 식별자 | `A-01` |
| **Status String** | String | `OCCUPIED` (입차) 또는 `EMPTY` (출차) | `OCCUPIED` / `EMPTY` |
| **Terminator** | Char | 패킷 종료 문자 | `\n` (`0x0A`, LF) |

#### 📌 실제 전송 예시
```text
$EVENT,A-01:OCCUPIED\n
$EVENT,B-02:EMPTY\n
```

## 4. 10개 주차 슬롯 매핑 테이블

| Slot ID (Index) | 슬롯명 (Slot Name) | ADC 채널 / Pin | 비트 마스크 (Bitmask) |
|:---:|:---:|:---:|:---:|
| 0 | **`A-01`** | PA0 (ADC1_IN0) | `0x0001` (1U << 0) |
| 1 | **`A-02`** | PA1 (ADC1_IN1) | `0x0002` (1U << 1) |
| 2 | **`A-03`** | PA4 (ADC1_IN4) | `0x0004` (1U << 2) |
| 3 | **`A-04`** | PB0 (ADC1_IN8) | `0x0008` (1U << 3) |
| 4 | **`A-05`** | PC0 (ADC1_IN10) | `0x0010` (1U << 4) |
| 5 | **`A-06`** | PC1 (ADC1_IN11) | `0x0020` (1U << 5) |
| 6 | **`B-01`** | PA6 (ADC1_IN6) | `0x0040` (1U << 6) |
| 7 | **`B-02`** | PA7 (ADC1_IN7) | `0x0080` (1U << 7) |
| 8 | **`C-01`** | PC2 (ADC1_IN12) | `0x0100` (1U << 8) |
| 9 | **`C-02`** | PC4 (ADC1_IN14) | `0x0200` (1U << 9) |

## 5. 수신단 (InfoMark) C 구현 및 파싱 예제

### 5.1. `$PARK` 파싱 함수 예제

```c
#include <stdio.h>
#include <string.h>
#include <stdbool.h>

/**
 * @brief 수신된 $PARK 패킷을 파싱하여 주차 모델/상태를 업데이트
 * @param rx_packet 수신된 NULL-terminated 문자열 (예: "$PARK,A-01:1,A-02:0...\n")
 */
void parseParkingPacket(char *rx_packet) {
    if (rx_packet == NULL) return;

    /* 1. $PARK 패킷인지 확인 */
    if (strncmp(rx_packet, "$PARK,", 6) == 0) {
        char *token = strtok(rx_packet + 6, ",\n\r");
        
        while (token != NULL) {
            char slot_name[16] = {0};
            int is_occupied = 0;

            /* "A-01:1" 형태 분리 */
            if (sscanf(token, "%[^:]:%d", slot_name, &is_occupied) == 2) {
                // TODO: 수신단 모델 업데이트 로직 호출
                // parkingModelSetStatus(slot_name, (is_occupied == 1));
                printf("[PARK SYNC] Slot %s -> %s\r\n", slot_name, is_occupied ? "OCCUPIED" : "EMPTY");
            }
            token = strtok(NULL, ",\n\r");
        }
    }
    /* 2. $EVENT 단일 이벤트 패킷 확인 */
    else if (strncmp(rx_packet, "$EVENT,", 7) == 0) {
        char slot_name[16] = {0};
        char status_str[16] = {0};

        if (sscanf(rx_packet + 7, "%[^:]:%s", slot_name, status_str) == 2) {
            bool is_occupied = (strcmp(status_str, "OCCUPIED") == 0);
            printf("[EVENT] Slot %s -> %s\r\n", slot_name, status_str);
        }
    }
}
```
